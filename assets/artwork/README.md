# Brush frame

`brush-frame.svg` preserves the two supplied red vector strokes and their
looping seven-second scale animation. A static thumbnail and the same animation
are bundled in `scripts/custom-library.js` for offline browsing.

The source was embedded vector data from the user's Tirelire archive. The archive
and its logo were removed at the user's request. No source license was provided;
this supplied artwork is not included in the original studio collection's CC0 grant.
