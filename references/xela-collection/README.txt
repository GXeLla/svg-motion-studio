XeLa All SVG + PNG Pack

This combined pack merges all delivered collections into one simple structure.

Folders:
- SVG/ : all SVG files
- PNG_Reference/ : matching PNG reference files

Totals: 81 SVG files and 81 PNG files.

Naming:
- P1_ = Collection 01
- P2_ = Collection 02
- P3_ = Collection 03
- FX_ = Selected effects pack
- S25_ = Selected 25 pack

Collection summary:
- P1: 10 artworks
- P2: 10 artworks
- P3: 5 artworks
- FX: 31 selected effects (icon #4 removed as requested)
- S25: 25 selected assets from the newer boards

Notes:
- PNG files are the reference images/crops.
- SVG files are the vector-traced versions prepared for your Motion Studio workflow.
- Some SVGs are automatic vector tracings, so fine details can be simplified.
- Filenames keep short prefixes so the pack stays sorted and easy to browse.

- P1_01_botanical_lady

- P3_03_phoenix_emblem
